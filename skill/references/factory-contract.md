# Route3 factory contract (v1 — SHIP-WITH-CUTS)

Callers: `SKILL.md` progressive row; `build-pipeline.md`; `scripts/init-run.sh`;
`check-stage.sh`; `context-pack.sh`; `verify-slice.sh`; `check-plan-done.sh --factory`.

**Iron law:** Factory is **opt-in**. Default Build stays slim-v3 (`standard`).
No new permanent agents in v1. No 5 human mid-gates. No FINAL PR automation.

## Risk paths (required)

| Path | When | Spine |
|---|---|---|
| `trivial` | typo / ~20-line rename; no schema/auth/pay | skip factory; `--trivial` done |
| `standard` | default 80% features | clarify → plan approval → slice → verify → review → done |
| `factory` | multi-slice **or** high-risk (auth/pay/PII/migration/multi-module) | run-dir + stages below |

Set once after clarify (prefer script):

```bash
scripts/classify-risk.sh --write PLAN.md
# or: scripts/check-preflight.sh PLAN.md --classify
```

```text
FACTORY: class=trivial|standard|factory reason=…
RISK_SIGNALS: …
```

Rules: trivial ONLY if `SKIPPED_TRIVIAL` + `TRIVIAL_REASON` and no high-risk tokens;
factory on auth|2fa|payment|pii|refund|rbac|tenant|migration|prisma schema|
multi-slice|slices:N≥2|security|production; else standard. Fail closed toward safer.

`class=factory` without `init-run.sh` → treat as standard until run exists.

## Gate kinds (approval dichotomy)

| Kind | Who | Examples |
|---|---|---|
| **VALIDATED** | script / specialist agent | research complete, arch sections present, verify-slice PASS |
| **APPROVED** | **human user only** | `PLAN_APPROVAL` (exactly one pre-code human gate) |

Existing user gates unchanged: destructive / prod / money / secrets / publish / dependency.
**Never** auto-`APPROVED` overnight. Overnight: freeze plan at queue time only.

Internal stage markers use `VALIDATED`, not `APPROVED`.

## Artifact layout (factory path only)

```text
.workflow/route3/runs/<run-id>/
  STATE.json
  01-RESEARCH.md          # optional unless researcher/NBLM triggered
  02-PRODUCT.md           # or PLAN PRODUCT: block (either OK)
  03-ARCHITECTURE.md
  05-PLAN.md              # or copy of working PLAN
  CONTEXT.md              # generated per slice by context-pack.sh
  slices/<NNN>/
    BRIEF.md
    VERIFY.md             # generated by verify-slice.sh — never builder prose
  TRACE.jsonl             # append-only transitions (thin)
```

**No `04-PROGRAM-DESIGN.md` in v1.** Contracts + ownership + file surfaces live in
`03-ARCHITECTURE.md` + per-slice `BRIEF.md`. Call graphs = builder work.

## Truth precedence

1. `STATE.json` (authoritative machine state)
2. Stage / BRIEF files (decisions)
3. `VERIFY.md` (observations / evidence)
4. `TRACE.jsonl` (audit only — never overrides STATE)
5. Legacy PLAN markers (compat bridge; write-through when possible)

## Stage machine (factory)

Legal forward: `init → research? → product → architecture → plan → slice* → final_verify → done`

| Stage | VALIDATED when |
|---|---|
| research | `01-RESEARCH.md` has EVIDENCE + findings; or skipped in STATE |
| product | `02-PRODUCT.md` **or** PLAN `PRODUCT:` + AC list; min sections; verdict not `SCRAP`/`PARK`/`NEEDS_MORE_INPUT` (see below) |
| architecture | `03-ARCHITECTURE.md`: services/modules, contracts, data, failures, security |
| plan | `05-PLAN.md` or PLAN: slices listed + `PLAN_APPROVAL` human line |
| slice | BRIEF digest frozen → route → dispatch → verify-slice PASS → reviewer |
| final_verify | head-SHA integration commands PASS |

Upstream digest change → downstream stages set `STALE` (must re-validate).

**Edge rule (graph discipline):** a slice may depend on a prior slice only if it
**consumes its artifact/data** (contract, schema, generated type). Ordering with no
data flow is a fake dependency — run it in the same wave. Barrier (wait for the whole
set) only for true fan-in: dedupe, compare, ship gate. See `parallel-ownership.md`
§ Graph discipline.

### Product verdict gate (product stage)

`route3-product` **may refuse.** `02-PRODUCT.md` (or the PLAN `PRODUCT:` block) carries
one `VERDICT:` line — `BUILD | BUILD_SMALLER | PARK | SCRAP | NEEDS_MORE_INPUT`
(contract: `agents/route3-product.md`).

| Verdict | product stage |
|---|---|
| `BUILD` / `BUILD_SMALLER` | VALIDATED (artifact rules still apply) |
| `SCRAP` / `PARK` | **not** VALIDATED — architecture must not run |
| `NEEDS_MORE_INPUT` | not VALIDATED — clarify, then re-run product |
| missing | warn only (backward compatible with pre-1.4.3 runs) |

Only a recorded **human** override passes a refusal, in PLAN or the product artifact:

```text
PRODUCT_OVERRIDE: approved by user at 2026-08-08T09:30:00Z reason=strategic bet, evidence pending
```

Boss may not write that line for the user (`boss-discipline.md`). Enforced by
`check-stage.sh --run ID product`. The verdict decides *whether to build* — it never
lowers the bar: `BUILD_SMALLER` means fewer AC, still SaaS production-complete.

## CONTEXT package

Built by `context-pack.sh --run <id> --slice <NNN>`.
Includes: TASK, PRODUCT/ARCH excerpts, BRIEF, repo instruction paths, file
manifest+hashes, prior VERIFY, open risks, `FACTORY` class.
**Isolate conversation noise — not the repository.**
Builder may log `EXPANSION_REQUEST:` for read-only paths beyond the package;
grant is logged in TRACE.

## Boss authority (factory)

Boss may: `init-run`, dispatch, run gate scripts, record observed transitions.
Boss may **not**: author product/arch content, rescue-fix verify failures, write
reviewer verdicts, or self-approve stages. See `boss-discipline.md`.

## Stale invalidation (mandatory)

```bash
scripts/invalidate-stale.sh --run "$RUN_ID"
```

Recomputes digests for `01-RESEARCH` / `02-PRODUCT` / `03-ARCHITECTURE` / `05-PLAN`
vs `STATE.artifacts`. Mismatch → artifact `STALE` + all slices `STALE`. Exit 1 if
any upstream STALE. `check-plan-done.sh --factory` runs this and fails closed.

## Lessons (mandatory self-improve)

On verify FAIL / reviewer FIX|REJECT / BUILD_PROOF fail → `record-lesson.sh`.
See `self-improve.md`. Factory done requires lesson attempt when any slice blocked
or VERIFY FAIL without `LESSON_RECORDED`.
