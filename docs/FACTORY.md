# Factory path

Opt-in high-risk / multi-slice spine. Default Build remains slim-v3 **standard**. Contract source: `skill/references/factory-contract.md`.

## classify-risk rules

```bash
scripts/classify-risk.sh [--write] [PLAN.md]
# stdin or default PLAN.md / .workflow/PLAN.md / .workflow/route3/PLAN.md
```

| Result | Rules |
|---|---|
| `trivial` | `status=SKIPPED_TRIVIAL` **and** `TRIVIAL_REASON:` present **and** no factory tokens |
| `factory` | Any high-risk / multi-slice token (see below) |
| `standard` | Everything else (default) |

Factory tokens (fail closed): `auth`, `2fa`, `payment`, `pii`, `refund`, `rbac`, `tenant`, `migration`, `prisma schema`, `multi-slice`, `slices:N` (≥2), `security`, `production`.

Writes (with `--write`):

```text
FACTORY: class=trivial|standard|factory reason=…
RISK_SIGNALS: …
```

`class=factory` without a run directory → treat as standard until `init-run.sh` succeeds.

## init-run layout

```bash
scripts/init-run.sh --path factory|standard [--plan PLAN.md] [--run-id ID] [--overnight-item ID]
# prints RUN_ID=… RUN_DIR=…
```

```text
.workflow/route3/runs/<run-id>/
  STATE.json              # authoritative
  01-RESEARCH.md          # optional unless researcher/NBLM
  02-PRODUCT.md           # or PLAN PRODUCT: block
  03-ARCHITECTURE.md
  05-PLAN.md              # copy of working PLAN when provided
  CONTEXT.md              # from context-pack.sh (per slice refresh)
  slices/<NNN>/
    BRIEF.md
    VERIFY.md             # generated by verify-slice — never builder prose
  TRACE.jsonl             # append-only transitions
```

No `04-PROGRAM-DESIGN.md` in v1. Contracts + ownership live in architecture + BRIEF.

## Stages + check-stage

Legal forward: `init → research? → product → architecture → plan → slice* → final_verify → done`

```bash
scripts/check-stage.sh --run RUN_ID <research|product|architecture|plan|slice> [--slice NNN]
# exit 0 VALIDATED | 1 FAIL
```

| Stage | VALIDATED when |
|---|---|
| research | `01-RESEARCH.md` has EVIDENCE + findings; or `research_skipped` in STATE |
| product | `02-PRODUCT.md` (problem/scope/AC, no TBD) **or** PLAN `PRODUCT:` + AC |
| architecture | `03-ARCHITECTURE.md`: module/service, contract, data, failure, security |
| plan | Plan file + human `PLAN_APPROVAL: approved\|continue\|yes_to_all` + slice list |
| slice | BRIEF digest frozen → route → dispatch → verify-slice PASS → reviewer |

Internal markers use **VALIDATED**, not APPROVED. Only humans APPROVE the plan.

## BRIEF + verify presets

Required BRIEF fields (YAML front / structured):

```yaml
slice: "001"
goal: "…"
allowed_files: ["src/…"]
must_not_change: ["…"]
acceptance:
  - id: AC1
    text: "…"
verify:
  - lint
  - tsc
  - "npm run lint"   # full commands also OK
```

`verify-slice.sh --run ID --slice NNN` resolves presets **before** allowlist:

| Preset | Resolves to |
|---|---|
| `lint` | `npm run lint` |
| `tsc` | `npx tsc --noEmit` |
| `test` | `npm test` |
| `test:unit` | `npm run test -- --run` (fallback `npm test`) |

Allowlisted prefixes after resolve: `npm `, `npx `, `pnpm `, `yarn `, `node `, `python3 `, `pytest `, `vitest `, `cargo `, `go test`, `dotnet `, `make `, `bundle exec `, `tsc`, `eslint`.

On FAIL, writes `VERIFY.md` evidence and typically auto-calls `record-lesson.sh`.

## context-pack + EXPANSION_REQUEST

```bash
scripts/context-pack.sh --run RUN_ID --slice NNN
# → RUN_DIR/CONTEXT.md
```

Includes: FACTORY class/stage, BRIEF, PRODUCT/ARCH excerpts, repo rule paths, file manifest, prior VERIFY, **ACTIVE LESSONS (last 5)**.

Header line:

```text
EXPANSION_REQUEST: (builder may append read-only paths; grant logged in TRACE)
```

Builders may request extra **read-only** paths; grants append to TRACE. Conversation noise is isolated — not the repository.

## invalidate-stale

```bash
scripts/invalidate-stale.sh --run RUN_ID
# exit 0 clean | 1 any STALE
```

Recomputes digests for research / product / architecture / plan vs `STATE.artifacts`. Mismatch → artifact `STALE` + slices `STALE`. `check-plan-done.sh --factory` runs this and fails closed.

After STALE: re-validate upstream stages; refresh affected BRIEF digests; do not pretend prior VERIFY still holds.

## check-plan-done --factory

```bash
scripts/check-plan-done.sh --factory --run RUN_ID [PLAN.md]
```

Requires `--run`. Uses run `05-PLAN.md` when present. Factory mode additionally requires:

- Stale check clean (or fail)
- Slice terminals acceptable
- Lesson attempts when VERIFY FAIL / blocked slices (see [SELF-IMPROVE.md](SELF-IMPROVE.md))

Standard / trivial / domain modes keep the legacy PLAN token checks (`--trivial`, `--domain`, `--full`).

## overnight-factory bridge

```bash
scripts/init-run.sh --path factory --overnight-item ITEM_ID
scripts/link-overnight.sh --run RUN_ID --item ITEM_ID
```

Rules:

1. Human `PLAN_APPROVAL` before overnight only (freeze plan at queue time).
2. Mid-loop: no human stage gates.
3. STALE → pause queue item (`paused_for_morning`); do not auto-expand scope.
4. Morning report: slice terminals + lessons from `LESSONS.jsonl` / TRACE.

`link-overnight.sh` patches `.workflow/night-shift/QUEUE.json` when present; else writes `.workflow/night-shift/links/$ITEM_ID` → `run_id`.

See `skill/references/overnight-factory.md` and `cli-backends.md`.
